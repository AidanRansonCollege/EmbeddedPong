## Components
ESP32, Sunfounder ESP32 Starter Kit
Web Server, hosted on the ESP32 using HTTP
Web UI, using HTML and CSS
LCD Display

## Libraries
ESPAsyncWebServer from https://github.com/mathieucarbou/ESPAsyncWebServer
AsyncTCP from https://github.com/ESP32Async/AsyncTCP
WiFi available from the Arduino Library Manager
LiquidCrystal from Arduino Library Manager
